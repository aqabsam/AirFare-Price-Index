# Tech Stack

## Frontend

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Recharts**
- **React Router**

## Backend

- **Node.js**
- **Fastify**
- **TypeScript**
- **Playwright**
- **node-cron**

## Database

- **PostgreSQL**

## Extra Tools

- **Axios** for API calls
- **Lucide React** for icons
- **Zod** for validation
- **dotenv** for environment variables
- **pg** for PostgreSQL access

## Simple Summary

The app uses **React** for the user interface, **Fastify** and **Node.js** for the server, **Playwright** to collect live flight data, and **PostgreSQL** to store and analyze the fares.
